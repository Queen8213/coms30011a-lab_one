  The causal chain:

  1. "Fill out this field" is Chrome's valueMissing message. It fires on one
  condition only — input.value === "". Not a range rejection; a range violation

  browser's DOM never matched React's tree. On hydration failure React 19 throws
  away the server DOM and re-renders the whole root client-side. That replaces 
  the input's DOM node, discarding your typed date — while the picker can still
  look populated. Submit then hits required on an empty value.

  proved the server action happily accepts today's date, and it does — the
